A few things you might be wondering.

Can I browse without signing in?

Yes. Search all sample jobs, use filters, read job details, and save favorites for the current session without an account.

Why do I need an account to apply?

An account keeps your application drafts and résumé associated with you. If you select Apply as a guest, the app asks you to sign in or create an account and then returns you to the selected opportunity.

Are these real vacancies?

This is an internship portfolio demo. Original sample roles never receive applications. The separate employer-listing workspace demonstrates posting, moderation, submission and status tracking using fictional companies and candidate data. No hiring outcome is promised.
